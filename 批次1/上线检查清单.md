# 上线检查清单

改完任何东西后，先跑这一条自检，绿了再往下走：

```
node check-seo.mjs
```

---

## 一、上线前必做

**1. 换域名（最关键，别忘）**

现在的域名占位是 `soker-website.vercel.app`，全站共 22 处引用。不要手动改，用一条命令：

```
node check-seo.mjs --domain https://你的正式域名
```

然后复查：

```
node check-seo.mjs
```

要看到「0 项必须修」才算过。

**2. 确认三个入口文件跟着部署了**

浏览器打开这三个地址，能看到内容才算成功：

- `你的域名/robots.txt`
- `你的域名/sitemap.xml`
- `你的域名/llms.txt`

**3. 首页底部露出 ICP 备案号**

备案号 `浙ICP备2021004016号-2` 现在只出现在「首批内测」页底部。国内访问要求首页可见，建议在上线前放到首页能直接看到的位置。

## 三、需要你拍板的 4 件事（我改不了）

1. **正式域名是什么** —— 决定了 canonical 指向哪里。
2. **公司主体名** —— 页脚写的是 `Byering.com`，对外品牌是「百聆」。搜索引擎和 AI 判断「是不是同一家公司」靠这个一致性，现在两边对不上。
3. **抖音号 / 公众号链接** —— 结构化数据里的 `sameAs` 目前是空的。补上之后，AI 才敢确认官网和你的社交账号是同一个人/公司。
4. **内测表单要不要真收线索** —— 现在是纯视觉演示，不发送不保存。这意味着所有来的人都没有留下联系方式。

---

## 四、下一步值得做（按性价比排序）

1. **行业落地页**：`/car`、`/property`、`/insurance`…… 每个页面对准一个真实搜索词（如「二手车销售怎么找客户」）。现在全站只有一个首页加一个 FAQ 页，能承接的长尾词太少。
2. **案例页**：等有真实客户之后再做。没有真实数据之前不要编，编了被 AI 引用出去是要还的。
3. **每季度更新一次** `llms.txt` 和 `faq.html` 里的「最近更新」日期 —— 引擎和 AI 都会看内容新鲜度。

| `soker.css` | 新增 `.hero-definition`、`.soker-fallback-title`、`.soker-guide-more` 样式 |
| `_astro/hoisted.8bfbdbf3.js` | **打了补丁**：`document.getElementById("section-0").querySelector("h2")` 改为 `querySelector("h1, h2")` |

### 关于那个补丁（重要）

3D 标题动画在打包文件里**写死**了 `querySelector("h2")`，只认 h2。把首屏标题改成 h1 之后，这行返回 null，整个 3D 初始化抛异常，页面卡在开屏、内容全部不显示。

现在已改成 `querySelector("h1, h2")`，两种标签都能识别。

**注意**：`_astro/` 是编译产物。如果以后从原仓库重新构建，这个补丁会被覆盖，h1 又会把页面搞崩。重新构建后请确认这一行仍是 `"h1, h2"`，或者干脆把改标题标签这件事同步到 Astro 源码里。

## 首屏加载优化（第三轮）

初次打开要拉 6 个场景的模型文件（`.buf`），未压缩时桌面端约 9.5MB，手机 4G 下首屏要 30 秒才能看到内容。

处理办法：把 `.buf` 就地 gzip，浏览器看到 `Content-Encoding: gzip` 会自动解压，前端 JS 读到的仍是原始字节，**不需要改任何前端代码**。

| 文件 | 改动 |
|---|---|
| `assets/models/**/*.buf` | 61 个文件就地 gzip，17.82MB → 11.15MB（省 37%） |
| `server.mjs` | 遇到 `.buf` 且文件头是 gzip 时补 `Content-Encoding: gzip` 与 `Vary`（按文件头判断，天然幂等） |
| `vercel.json` | 给 `/assets/models/*.buf` 加 `Content-Encoding: gzip` 响应头 |
| `tools/compress-models.mjs` | 新建。`node tools/compress-models.mjs` 压缩，`--check` 只检查，`--restore` 还原 |

### 上手须知

- 设计那边重新导出模型后，`.buf` 会变回未压缩状态，记得跑一次 `node tools/compress-models.mjs`，再用 `--check` 确认。
- 线上如果首屏 3D 不显示（白屏只剩弹窗），第一嫌疑就是 `Content-Encoding` 没生效或双重压缩。排查：浏览器 DevTools → Network → 看 `SCENE.buf` 的状态码是否为 200 且带 `Content-Encoding: gzip`。真出问题就先 `node tools/compress-models.mjs --restore` 还原、删掉 `vercel.json` 里那条规则，重新部署可回到原状。
